# ubuntu shortcut

## toggle view

```sh
ctrl + b ## show/hide left sidebar
ctrl + shift + g ## source controlCtrl + Shift + G	Open Source Control
ctrl + shift + f ## search globally
ctrl + shift + e ## show explorer

ctrl + j ## show/hide button bar
ctrl + ` ## terminal view

ctrl + alt + b ## show/hide right sidebar
```

## command

```sh
ctrl + p ## command

```

## cursor movement

```sh
ctrl + G ## jump to line
ctrl + shift + o ## search function in current file
ctrl + t ## search function in entire workspace.
```

## browse

```sh
PgUp / PgDn ## scroll current file
Ctrl + PgUp/PgDn ## scroll left/right tab
```
